## Recommended backend architecture
For a production CMS, keep the frontend components reusable and expose:
- `/properties`
- `/properties/:slug`
- `/enquiries`
- `/testimonials`
- `/insights`

Store private property documents in protected storage and never expose them through public image/document URLs.

## Trust rules
Do not publish:
- invented properties/prices
- fake testimonials
- unverified certification/RERA/government approval claims
- guaranteed appreciation/returns/profits
- unsupported “100% verified” claims

Verify property information independently before transaction or investment.
