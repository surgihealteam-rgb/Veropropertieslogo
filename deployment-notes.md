# Production checklist

1. Replace `YOUR-DOMAIN.example` in `robots.txt` and `sitemap.xml`.
2. Replace the clearly marked demo property cards with verified VERO inventory.
3. Connect `data/properties.json` to the selected CMS/database.
4. Add real office address and Google Maps link when available.
5. Replace placeholder social links in the footer with official VERO profiles.
6. Add verified Privacy Policy, Terms & Conditions and Disclaimer pages.
7. Configure Google Analytics / Search Console and Meta Pixel.
8. Add server-side spam protection for any backend form endpoint if introduced.
9. Serve images through an optimized CDN/WebP/AVIF pipeline and lazy-load property galleries.
10. Keep property documents private; only expose verification status and safe summaries publicly.
